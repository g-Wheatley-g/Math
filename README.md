# Математика · Подготовка к экзамену

Сайт охватывает 56 тем математического анализа, 24 темы линейной алгебры и дополнительную тему о комплексных числах. В каждой теме есть теория, разобранные примеры и два практических задания.

## Запуск

Откройте `dist/index.html` в актуальном Firefox, Chrome, Edge или Safari. Сайт работает без интернета и не требует установки пакетов. Формулы отображаются с помощью MathML.

Для запуска через локальный сервер выполните команду из корня репозитория и откройте `http://localhost:8000`.

```sh
python3 -m http.server 8000 --directory dist
```

## Учебные материалы

Содержимое перенесено из «Математика_для_сайта.docx». В карточках тем указаны источники из Word. Страница «Источники и пробелы» содержит замечания к исходникам и отмечает случаи, для которых в документе нет отдельного примера.

В задании с выбором ответ проверяется сразу. При самостоятельном вводе сайт показывает введённый и правильный ответы рядом. Решение можно раскрыть под каждым заданием.

## Обновление материала

Для повторного импорта Word нужны Pandoc (проверено с версией 3.1.11.1) и Python 3 с `lxml`. Скрипт проверяет структуру исходного документа и формирует `dist/guide.js` и иллюстрации в `dist/media/`.

```sh
python3 scripts/import_word.py "/путь/к/Математика_для_сайта.docx"
```
